# Theory of Computation Lab

This repository contains C/C++ programs developed as part of the Theory of Computation (TOC) laboratory. The programs demonstrate the implementation and simulation of different computational models, including DFA, NFA, Moore Machine, and PDA.

## Topics Covered

- DFA to accept strings ending with `101`
- DFA to accept strings containing three consecutive `1`s
- DFA to accept binary strings with remainder `0` when divided by `3`
- DFA to accept decimal numbers divisible by `2`
- Moore Machine to count the number of `0`s and `1`s
- Moore Machine to find the 2's complement of a binary number
- PDA to accept strings having an equal number of `0`s and `1`s
- NFA implementation using transition tables
- NFA input and transition handling using `Nfa_ip.txt`

## Technologies

- C
- C++

## Purpose

The programs are intended for laboratory practice and demonstrate how formal computational models can be represented and simulated using programming languages.

## Notes

- Some programs use `system("cls")` and are intended for Windows environments.
- `Nfa_ip.txt` is used as an input file for the NFA implementation.
- Programs are kept simple and focused on demonstrating the underlying TOC concepts.
